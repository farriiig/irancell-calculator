نسخه PWA محاسبه‌گر اینترنت داخلی ایرانسل

فایل‌ها:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

نصب:
1) کل پوشه را روی یک هاست HTTPS قرار دهید.
2) index.html را در Chrome اندروید باز کنید.
3) گزینه Install app / Add to Home Screen را بزنید.
4) پس از اولین بارگذاری، برنامه آفلاین هم قابل اجراست.

نکته:
PWA از file:// به‌صورت کامل نصب نمی‌شود؛ باید از HTTPS یا localhost اجرا شود.
